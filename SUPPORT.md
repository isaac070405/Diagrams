# Support

- **Use the workspace:** open https://isaac070405.github.io/Diagrams/. The [README](README.md) describes each diagram type.
- **Build from source:** follow [source/README.md](source/README.md).
- **Report a bug or request a feature:** open an [issue](https://github.com/isaac070405/Diagrams/issues) with the diagram type, browser and steps to reproduce.
- **Report a security problem:** follow [SECURITY.md](SECURITY.md).
- **Contribute:** read [CONTRIBUTING.md](CONTRIBUTING.md).

This is a student-maintained project. Replies may take several days.
